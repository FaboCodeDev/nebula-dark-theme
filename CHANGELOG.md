# Changelog

All notable changes to the "Nebula Dark Theme" extension will be documented in this file.

## [1.0.0] - 2024-03-20

### Initial Release
- **Nebula Dark Vibrant**: High contrast, vibrant colors version
- **Nebula Dark Muted**: Subtle contrast, muted tones version
- Base colors: #121212 (background) and #6610f2 (primary accent)
- Optimized for multiple programming languages
- Published by Fabocode
- GitHub: https://github.com/FaboCodeDev/nebula-dark-theme

### Features
- Two variants in one package
- Terminal with #1a1a1a background
- Git colors integration
- Bracket matching highlighting
- Consistent UI across all elements
- MIT License

### Supported Languages
- JavaScript/TypeScript (MERN Stack)
- PHP/Laravel
- Python
- C#/.NET and Unity
- HTML/CSS
- JSON, Markdown, and more
