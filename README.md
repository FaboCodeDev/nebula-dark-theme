## 🎨 Paleta de Colores

| Elemento | Código | Descripción |
|----------|--------|-------------|
| Fondo | `#121212` | Base oscura profunda, no agresiva para los ojos |
| Acento Primario | `#6610f2` | Violeta corporativo vibrante para elementos clave |
| Texto Principal | `#f8f9fa` | Blanco ahumado para óptimo contraste |
| Strings | `#20c997` | Verde esmeralda para excelente visibilidad |
| Números | `#ff6b6b` | Rojo coral para identificación inmediata |
| Keywords | `#339af0` | Azul cielo para palabras reservadas |
| Funciones | `#ff922b` | Naranja cálido para métodos y funciones |
| Comentarios | `#6c757d` | Gris medio legible pero no intrusivo |
| Terminal | `#1a1a1a` | Fondo sutilmente diferente para jerarquía visual |
| Clases/Tipos | `#da77f2` | Rosa violeta para definiciones de tipo |
| Git Añadido | `#51cf66` | Verde para archivos añadidos en Git |
| Git Modificado | `#ff922b` | Naranja para archivos modificados |
| Git Eliminado | `#ff6b6b` | Rojo para archivos eliminados |

## 🚀 Instalación

### Desde VS Code Marketplace
1. Abre VS Code
2. Ve a Extensiones (Ctrl+Shift+X)
3. Busca "Nebula Dark"
4. Haz clic en Install

### Manualmente desde .vsix
1. Descarga el archivo `.vsix`
2. En VS Code: `Ctrl+Shift+P` → `Extensions: Install from VSIX`
3. Selecciona el archivo descargado

## ⚙️ Uso

Después de instalar:
1. Presiona `Ctrl+Shift+P` (o `Cmd+Shift+P` en Mac)
2. Escribe "Preferences: Color Theme"
3. Selecciona "Nebula Dark" de la lista
